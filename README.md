# 灰燼の塔 — EMBER SPIRE / 灰烬之塔

スマートフォンでもPCでも遊べる、縦長画面のターン制ダンジョン探索RPG。
ファイルを開くだけで動き、追加のインストールやサーバーは不要です。

- **プレイ場所:** `ember-spire/index.html` をブラウザで開くだけ（ダブルクリックで開始）
- **外部依存:** Google Fonts（Zen Maru Gothic / Cinzel）のみ。ネット未接続でもフォールバックフォントで正常に遊べます
- **プラットフォーム:** iOS Safari / Android Chrome / Windows・macOS の Chrome・Edge・Firefox・Safari

---

## ゲーム内容

| 要素 | 内容 |
|---|---|
| 舞台 | B1階から続く生成式ダンジョン。**B10階にボス「灰燼竜」**。倒すと塔の宝を手にして勝利。そのまま無限の深部（B20に古灰燼竜）へも潜れる |
| 戦闘 | 敵のマスへ入って打つ接近戦、急所（クリティカル）、回避判定、視界内の敵へ自動で飛ぶ「火の玉」（MP6） |
| 成長 | 経験値でレベルアップ（最大体力・魔力が伸び、上昇時に全回復）。武器5段階・鎧4段階 |
| 探索 | 提灯の灯り＋霧（一度見た床は記憶される）。隠し罠、鍵のかかった扉と宝物庫、宝箱（**ミミックが潜む**）、gold、薬草 |
| 敵 | スライム／甲虫／コウモリ／ゴブリン／スケルトン／オウズ／大型蜘蛛（遠距離）／亡霊（二手移動）／インプ（遠距離）／山賊（goldを盗む）／鉄騎士／ミミック／灰燼竜 |
| ローグライク | 死ぬとそのrunは終了。セーブは消え、**記録（最深階層・討伐数など）だけが残る** |
| 操作 | 十字キー／スワイプ／タップ移動（自動歩行）／キーボード（矢印・WASD・Space・F・Q・Esc） |

## サウンド ON / OFF

画面上部の 🔊 チップ、または設定内のスイッチで切り替え。**状態は端末に保存**され、効果音と環境音（低弦のドローン＋稀に鳴る鐘）はすべて Web Audio API で合成した生音です（音声ファイル不使用）。

## 言語

**日本語 / English / 中文** の3言語。タイトル・プレイ中・設定のいずれからにも切り替え可能で、選択は保存されます。UI文言・メッセージ・品名・魔物名まで全て翻訳済み（翻訳キーの欠落は自動テストで検証）。

## セーブ（ローカル保存）

`localStorage` に保存されます。

- `ember-spire:save:v1` … 現在のrun（地形・視界・敵・アイテム・主人公）
- `ember-spire:meta:v1` … 言語・サウンド設定と通算記録

自動保存のタイミング：床を降りた時／4ターン毎／ポーズ時／タブを伏せた時／run終了時。タイトル画面の「続きから」から再開できます。死んだ場合、runのセーブは削除されます（記録は残る）。設定の「データを削除」で両方を消せます。

## 使い方

### タッチ（スマホ）
- **十字キー** … 移動。長押しで連走
- **盤面をスワイプ** … その方向へ移動
- **盤面をタップ** … そのマスまで自動歩行（危険な敵が視界に入れば自動で停止）。自分のマスをタップすると「休む」
- **火の玉 / 薬 / 休む** … 各アクション。休むと魔力+1だが、敵が寄ることがある

### キーボード（PC）
| キー | 動作 |
|---|---|
| ← ↑ → ↓ / WASD / hjkl | 移動（敵マスへ入れば攻撃） |
| Space | 休む |
| F | 火の玉 |
| Q | 薬草を使う |
| Esc | メニュー（ポーズ／設定／遊び方） |

## 実装構成

```
ember-spire/
  index.html          … 画面全体（HUD・盤面・操作・各種オーバーレイ）
  assets/
    style.css         … 縦長レイアウト。PCでは画面を縦の枠として中央表示
    i18n.js           … 3言語辞書と切り替え（{param}テンプレート、フォールバック）
    sprites.js        … 8x8の文字マップから生成するピクセルアート（画像ファイルなし）
    rules.js          … 能力値・敵・装備・経験値・ダメージ計算（純粋関数）
    dungeon.js        … 部屋+廊下の生成、視界(FOV/LOS)、経路探索(BFS)
    audio.js          … Web Audio で効果音と環境音を合成
    game.js           … 状態管理、ターン処理、UI描画、入力、保存
  tests/
    test-core.js      … Node で動くロジック検証
    browser-smoke.js  … headlessブラウザで実プレイ検証＋スクリーンショット
```

### 生成の約束
扉の錠（宝物庫）は、**鍵なしで階段へ到達できる場合にのみ**配置されます。階段へ行く手を塞ぐ錠は生成されないことを800フロア分のテストで保証しています。

### テスト
```bash
node tests/test-core.js       # 800フロア生成・接続性・鍵部屋・経路・翻訳キー・戦闘バランス
node tests/browser-smoke.js   # headless Edge/Chrome で起動→プレイ→保存→多言語→レイアウト
```
検証済み項目（すべて pass）: 起動とスクリプト読み込み / ウェブフォント / 3言語の表示切替 / 階層生成と階段降下 / 壁にぶつかってもターンを消費しない / 不正な移動の拒否 / スワイプ移動 / 自動歩行と中断 / rest・火の玉・薬 / localStorage保存と再開 / サウンド切替 / 死亡画面と記録更新・セーブ消去 / 再挑戦 / **390x844 のスマホ画面で縦長維持・スクロールなし・全ボタン40px以上** / コンソールエラー0件。

## 日本語 / English / 中文 概要

**日本語:** 縦長画面のターン制ダンジョンRPG。提灯の灯りの中で部屋と廊下を探し、B10階の灰燼竜を倒すと勝利します。死ねばrunは終了し記録のみ残るローグライク。3言語・サウンドON/OFF・localStorageセーブ対応。

**English:** A portrait-oriented turn-based dungeon crawler for phone and desktop. Carry a lantern through generated halls, grow strong on floors B1–B9, and slay the Cinder Dragon on B10 to claim the spire's treasure — death ends the run and only your record survives. Trilingual (ja/en/zh), synthesised sound with an on/off switch, and local save data in `localStorage`.

**中文:** 竖屏回合制地牢探索RPG，手机与电脑皆可游玩。提灯照亮随机生成的房间与走廊，击败 B10 层的灰烬龙即可获得塔中之宝；死亡即结束本次冒险，只留下战绩。支持日/英/中三语、音效开关，存档保存在本机 localStorage。
